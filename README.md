# 🎬 فيديو برو (Video Pro)

أداة ويب كاملة وحديثة تعمل في المتصفح لـ **الضغط مع القص** في عملية واحدة، مع الحفاظ على الجودة العالية. كل المعالجة تتم **محلياً على جهازك** داخل المتصفح باستخدام `ffmpeg.wasm` — **ملفاتك لا تُرفع لأي خادم، فخصوصيتك مضمونة 100%**.

يعمل المشروع على **GitHub Pages** مجاناً دون الحاجة إلى أي خادم.

---

## ✨ المزايا

- 🗜️ **ضغط الفيديو** بثلاث مستويات (خفيف / متوسط / عالي الجودة) عبر متحكم `CRF`، حصراً بصيغة **MP4**.
- ✂️ **قص جزء** قبل الضغط عبر تحديد نقطة البداية والنهاية (اختياري) — إن تُركت النهاية فارغة يُضغط الفيديو كاملاً.
- 📦 **تقسيم متسلسل (عدة مقاطع)**: كل 30 ثانية / دقيقة / دقيقتين / نصفين / أثلاث — ينتج مقاطع مرقّمة تلقائياً (مثل `30-1`, `30-2`, `30-3`...) مع كل مقطع للتحميل.
- 🎚️ **تحديد الدقة** للإخراج (1080p / 720p / 480p / 360p أو الدقة الأصلية).
- 🔒 **خصوصية كاملة** — كل شيء يعمل محلياً، لا رفع ملفات ولا خوادم.
- 📱 **متجاوب** ويعمل على الجوال والحاسوب.
- 🌐 **واجهة عربية** كاملة.

## 🚀 طريقة التشغيل محلياً

### الخطوة 0 — تثبيت (اختياري لكنه يُفضَّل كثيراً)
لتجنّب أي حجب لـ CDN الخارجي (مانع إعلانات/شبكة)، نزّل ملفات ffmpeg محلياً:
```bash
install.bat
# أو
python download-ffmpeg.py
```
سينشئ مجلد `lib/` فيه `ffmpeg.js` و `ffmpeg-core.js`، فيعمل التطبيق حتى بلا إنترنت.

### الخطوة 1 — تشغيل الخادم
**أسهل طريقة (Windows):**
```bash
start-server.bat     # يبدأ الخادم ويفتح المتصفح
stop-server.bat      # لإيقاف الخادم
```

**أو يدويّاً عبر Python:**
```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`

**أو عبر Node.js:**
```bash
npx serve -l 8080
```

> 💡 إذا لم يعمل الضغط وظهرت رسالة "حزمة ffmpeg غير محمّلة"، فالأغلب أن مانع إعلانات يحظر `unpkg.com`. الحل: شغّل `install.bat` لتنزيل الملفات محلياً، أو عطّل مانع الإعلانات في المتصفح.

## 🌍 الرفع على GitHub و تفعيل GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع (السحب والإفلات أو عبر git).
3. من إعدادات المستودع: **Settings → Pages**.
4. تحت **Source** اختر `Deploy from a branch`، ثم اختَر فرع `main` والمجلد `/ (root)`.
5. اضغط **Save** وانتظر دقيقتين.
6. سيُفتح موقعك على: `https://<اسم-مستخدمك>.github.io/<اسم-المستودع>/`

سيظهر رابط المستودع تلقائياً في أسفل الصفحة عند فتح الموقع من GitHub Pages.

## ⚙️ كيف يعمل؟

المشروع يستخدم مكتبة **[@ffmpeg/ffmpeg](https://github.com/ffmpegwasm/ffmpeg.wasm)** — نسخة من FFmpeg تُترجم إلى WebAssembly وتعمل داخل المتصفح مباشرة.

- **الضغط مع القص:** إعادة ترميز الفيديو بـ `libx264` ومتحكم جودة `CRF` (كلما انخفض `CRF` زادت الجودة وكبر الحجم). إذا حدّد المستخدم نقطة البداية والنهاية، يُطبَّق القص عبر خيارَي `-ss` و `-to` ضمن نفس عملية الضغط.
